# API-тест создания и получения заказа

Проект содержит автотест API для проверки сценария работы с заказом:

1. Создать заказ.
2. Получить трек заказа из ответа.
3. Запросить заказ по трек-номеру.
4. Проверить, что запрос заказа вернул HTTP 200.

## Структура проекта

- `tests/test_order.py` — автотест сценария.
- `data.py` — тестовые данные заказа.
- `helpers.py` — функции для HTTP-запросов.
- `requirements.txt` — зависимости проекта.
